**`MOD-011` no longer reports a documented `pub` associated const of a public type as code nothing calls.** The reachability check graded the methods of a public type as interface but not its associated consts, so the status codes of a binding crate (`impl cublasStatus_t { pub const SUCCESS: Self = ..; }`, reached through `pub mod status` and `pub use`) came out Medium "zero callers" while the same type's documented methods came out Info. The surface walk now records them (`const_sites`, `const_documented_sites`; a `pub use` out of a private module reaches them through the existing re-export sets), kept apart from `public_sites`, so the API budget does not change. Graded as a method is: documented is library API (Info), undocumented is exported (Info); a const of a type in a private module nothing re-exports stays Medium. **Output change: findings can only drop in severity; no new finding is produced; additive, no rule id, option or exit code changes.** **Measured by the coderipper lane on baracuda@5aeda2921 from the findings of its CI run 45205066007 (coderipper 0.47.15):** 322 Medium MOD-011 findings, all `pub const`, in 21 `-sys` crates (`baracuda-cuda-sys` 149, `baracuda-nvml-sys` 13, others); 0 named in the crate's own tests, examples or benches, 0 in any dependent crate's code, 0 in a doc example (3 bare-name hits are doc-comment prose); control: 186 of the 1763 `pub const`s in the 27 `-sys` crates are named by their wrapper crates and none is among the 322. Fixture crate at this change: a documented `pub const` on a type in `pub mod status` went Medium to Info, the documented method beside it stayed Info, and a const on a type in a private module nothing re-exports stayed Medium.
