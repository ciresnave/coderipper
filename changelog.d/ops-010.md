**OPS-010 is built in part: a Rust binary package that cannot report its version or build** (from the source and the manifest). A package with a `main.rs` or a `src/bin` file whose sources, `Cargo.toml` and `build.rs` name none of `CARGO_PKG_VERSION`, a clap `version`, `--version`, a build-information crate (`vergen`, `built`, `shadow-rs`, `git-version`) or a build-script variable (`cargo:rustc-env=`) is reported once. Info severity, Medium confidence, advisory. Not seen: a version printed by another package of the workspace, and whether the version carries a source revision. A package under a `fixtures`, `bench`, `benches`, `benchmarks`, `measure`, `xtask` or `testdata` directory, or named `*-bench`, is not read. Evidence: 55 Rust repos under `C:\Projects` (local checkouts, 2026-11-12): 7 binary packages reported at first, 4 of them a fixture, benchmark or measurement helper (excluded now); the remaining 3 (`claude-code-wrapper`, `consent`'s `user-request` and `with-secret`) are shipped tools with no version, so 3 of 3 genuine.
