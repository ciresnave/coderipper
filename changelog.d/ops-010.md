**OPS-010 is built in part: a Rust binary package that cannot report its version or build** (from the source and the manifest). A package with a `main.rs` or a `src/bin` file whose sources, `Cargo.toml` and `build.rs` name none of `CARGO_PKG_VERSION`, a clap `version`, `--version`, a build-information crate (`vergen`, `built`, `shadow-rs`, `git-version`) or a build-script variable (`cargo:rustc-env=`) is reported once. Info severity, Medium confidence, advisory. Not seen: a version printed by another package of the workspace, and whether the version carries a source revision.
