**`SUP-016` per-file licence gate, opt-in (ROADMAP row 18; decided by pm-platform 2026-11-22: opt-in settings on the one id, no new id).** A repository that sets `[sup016] gate = true` in its own `.coderipper.toml`, with `licence = "<SPDX expression>"` and `extensions = [".rs", ..]`, gets the contract of the portfolio's `spdx_gate.py`, so it can retire the script: every tracked file of a listed extension declares `SPDX-License-Identifier:` in its first `header_window` lines (default 10) and the identifier equals `licence` (the order of `OR` operands does not matter); fewer than `min_files` (default 20) stamped files is one finding and nothing else is judged (an empty population is not a pass); a tracked source extension in neither `extensions` nor `[sup016.not_stamped]` is a blind spot, and a `not_stamped` entry the tree no longer has is stale; `[sup016.holdout]` paths (a file whose licence is someone else's decision, with the reason) that are not tracked stamped files are stale; and a tracked file containing the word copyright that is not a licence file, a changelog, a notice, a holdout or a `copyright_expected` fragment is reported. Each finding is High with High confidence, so an opted-in repository reads red. Without the opt-in nothing changes. **Measured against the script** on a clone of `consent` at b5b8c41 (37 tracked source files; the script passes it): with the same six seeded defects the script and the rule name the same three files with no header, the same one with another licence, the same uncovered extension and the same copyright notice, and both pass it unseeded once the script's own five prose files are listed in `copyright_expected` (`tests/sup016_gate.rs` carries the seeded case). Differences kept on purpose: a file git takes for binary is skipped by the copyright survey; the repository's own `.coderipper.toml` is an expected copyright match (its key is named `copyright_expected`). Not built: a gate on files outside git, writing headers (the gate never writes).
