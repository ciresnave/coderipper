**Claims audit of the six Rust rules added in 0.47.12 (RDB-002, REL-002, ERR-002, TYP-004, ERR-007, OPS-007) and the MOD-011 extern-block change: four wrong claims corrected, every other documented claim now has a named test.** Each claim of a rule's module documentation, catalog `checked_today` and changelog entry was probed with a test; the four that failed are fixed. **(1)** `RDB-002` did not honour an inner `#![allow(non_snake_case)]`, `non_camel_case_types` or `non_upper_case_globals` on a file or module (see the entry above; the allow covers its own lint and its own scope). **(2)** `RDB-002` did not recognise `#[unsafe(no_mangle)]` and `#[unsafe(export_name = "..")]`, the edition-2024 spelling, so FFI exports written that way were reported; they are now left alone like `#[no_mangle]`. **(3)** `REL-002` read any call of a function with fixed or no arguments as a fixed delay, so `sleep(delay())` was reported as "no backoff" although the documentation says a fixed delay is one written out in the call; only a constructor path (`Duration::from_millis(100)`, `time::Duration::from_secs(1)`) with literal arguments, a literal or a `SCREAMING_CASE` name is fixed now. **(4)** A repository whose only Rust source file did not parse got "not applicable: tracks no Rust package source" from `RDB-002`, `REL-002`, `ERR-002`, `TYP-004`, `ERR-007` and `OPS-002`, which is false and names no file, while the documentation says an unparsable file is named in a note and never read as clean; it is now a note naming the file (`rust_package::nothing_to_read`; the other Rust rules that call `load` have the same pattern and are not changed here). Also: the `ERR-002` documentation said a bare `catch_unwind` counts when the file imports it; the code (and now the documentation) counts any call whose path ends in `catch_unwind`. Tests: the `claims` module of each of the six rules, `extern_block_*` tests for MOD-011 and the batch tests in `module::neutral::tests`. **Stated, not proved:** the `MOD-011` extern-block change's end-to-end effect (a finding at an extern symbol is graded Info, not Medium) is covered by classifier unit tests and by the coderipper lane's measurement on five `-sys` crates (Medium 2855 to 4, prototype build, `--no-config`), not by an end-to-end test; the full table of claims, proving tests and verdicts is `docs/rules/AUDIT-TABLE-0.47.12.md`.
