**MOD-011 no longer reports a `-sys` crate's `pub` extern-block symbols as code nothing calls.** The reachability check read `pub` functions, statics and types declared in an `extern "C" { .. }` block as nothing, so a binding crate's whole interface looked unreferenced. The surface walk now records them (`foreign_sites`, `foreign_documented_sites`) when the block sits in a module reachable through `pub` modules, and the classifier treats them as exported (library API when documented), so a finding at one is the Info "exported" class and not Medium dead code. The API budget is unchanged (the new sets are kept apart from `public_sites`). **Output change: findings can only drop in severity or disappear; no new finding is produced.** Not measured on a corpus of `-sys` crates. Tests: `a_pub_symbol_of_an_extern_block_is_exported_and_a_private_one_is_not`, `extern_block_symbols_are_kept_apart_from_the_budget`.
