**TYP-001 is built in part: a public Rust function that takes a domain value as a bare primitive** (`syn`, library code outside tests, examples, benches, `build.rs`, `main.rs` and `src/bin`). It reports, once per function, a parameter named for money (`price`, `amount`, `cost`, ...) or a duration (`timeout`, `ttl`, ...) and typed as a bare number, or two identifier parameters (`*_id`) of the same primitive type, which the compiler cannot tell apart if swapped. A name that states its unit (`timeout_ms`, `amount_cents`) is not reported; a lone `id: &str` is not reported. Low severity, Low confidence, default on in `extended` and `portfolio`, advisory, never gating. Evidence: the rule as shipped flagged 49 functions across the 55 Rust repos under `C:\Projects` (local checkouts, 2026-11-12); a hand read counts 44 genuine and 5 doubtful (3 `amount` parameters that are fuel, not money; one `language_id`; one `ttl` whose unit is in the function name), about 10% false positives. Before the narrowing to same-typed id pairs it flagged 1010 findings, mostly a lone `id: &str`, which is why a lone id is not reported.
