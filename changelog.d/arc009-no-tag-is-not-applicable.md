**ARC-009 is skipped, not "not run", in a repository that has never published a release.** With no tag `v<version>` reachable from `HEAD` and no `[arc009] base`, the rule reported "not run", and the portfolio job fails on any rule that did not run, so every never-published repository (lightbulb#314, fireline#17, ..) failed on the repin to 0.43.41. A repository that has not published has nothing to drift from: it is now a skip (`not_applicable_here`) with a note that says why (`ARC-009 skipped (not applicable here): ..`), counted as skipped in the coverage, never clean, never a failed job. New `Check::not_applicable` (default none); a skip with a reason now prints that reason as a note for every module. A repository that sets `[arc009] base`, or later tags a release, is compared as before. Measured on a tagless repository: the 0.43.20 build's note matches the portfolio gate's `not run:` filter (job fails); this build's note does not.
