kind: Added: RDB-007 (opt-in, Rust)
---
**RDB-007 is built in part, Rust only, opt-in.** Run it by naming it, `coderipper check RDB-007`; it is in no profile. It reads production source with `syn` and reports **one Info finding per file at low confidence**, at the first site, with the counts and the first sites, for two shapes: a number that is an operand of an arithmetic or comparison operator or an argument of a function or method call and is not trivial (`0`, `1`, `2`, `10`, `100`, `1000`, `1024`, `255`, `60`, `24`, the powers of two up to `4096`, `0.0`, `1.0`, `0.5`; a negated trivial value is trivial), and a string of two or more characters that appears three or more times in the file. Not read: `const` and `static` items, enum discriminants, array lengths, attributes, macro arguments (so format strings), the arguments of a tuple-struct or enum constructor, tests. A literal is a cue to read, never a verdict; the allowlist subject is the file path. Not seen: a literal inside a macro or copied through a variable, a string repeated across files; TypeScript and Python are not read. Fixtures `conformance/RDB-007/{clean,defective}`; the corpus counts are in the pull request. Patent sweep addendum: one idea, no hit read as claimed.
