**TypeScript `ERR-009`: a secret-named value interpolated into an error message** (ROADMAP items 8 and 12, seventh rule of the TypeScript module). `new XError(`...`)` (any constructor whose name ends in `Error`) whose first argument is a template string with a `${...}` substitution that is a plain identifier or a property whose name holds `password`, `passwd`, `secret`, `credential`, `apikey` or `privatekey` is reported. High severity, Low confidence (a name reading, no data flow), one finding per site; opt-in (`check ERR-009`). `token` is deliberately not a secret word (lexers and parsers); calls, literals, plain strings, comments and non-error constructors are not judged. Proof: `conformance-typescript/ERR-009` (one seeded defect, a clean twin that names the user only).
