kind: Breaking: a new opt-in rule (TST-006)
---
**TST-006 is built in part, opt-in** (`coderipper check TST-006`; `src/module/neutral/tst006.rs`, the neutral module's Rust reading, a static proxy). It reports a `#[test]` function (any `#[test]`, `#[tokio::test]` and the like) whose body **connects out** (`TcpStream::connect`, `UdpSocket::connect`, or `get`/`post`/... on `reqwest`, `ureq`, `surf` or `isahc`), **reads the wall clock** (`SystemTime::now`, `Utc::now`, `Local::now`, `OffsetDateTime::now_utc`, `Timestamp::now`, `Zoned::now`) or **names a shared location** (a string literal under `/tmp`, `/var`, `/etc`, `/home`, `/usr`, `C:` or `~/`, or a call to `env::temp_dir`), one Medium-severity, Low-confidence finding per test naming the kinds found. A test that binds a `TcpListener` or names a loopback address is a local-server test and its network calls are not reported; `#[ignore]` tests and `Instant::now` are left alone. It cannot see reach made by a helper, a fixture or the code under test; the full rule (run the suite offline with the clock frozen) is not built, and the record says so (`checked_today`).
**Proven and measured.** `coderipper conformance --module neutral --rule TST-006` is proven by the fixtures in `conformance/TST-006`, and two mutations turn it red (the clock branch removed: the seeded defect is not reported; the loopback exemption removed: the clean twin is reported). **Corpus** (eight committed trees at 2026-11-07: coderipper, auth-framework, Unpopped, PersistAnt, configurant, httpant, releaseant, synapse): **175 sites**, 124 reading the clock, 48 naming a shared path, 1 reaching the network and 2 two kinds (auth-framework 107, synapse 20, coderipper 14, Unpopped 12, configurant 11, PersistAnt 8, httpant 2, releaseant 1). Reading the names, most clock sites build a value stamped with `now` (a token or session) and some of the shared-path sites use a path literal such as `/etc/passwd` as data for a path-traversal test, not as a file to open, so the rule is noisy and is opt-in and Low confidence for that reason (the sites were read by name, not each one by hand).
