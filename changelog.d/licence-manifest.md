**SUP-022 to SUP-026 are built: the licence and attribution check, over `LICENCE-MANIFEST.toml`** (default on in `extended` and `portfolio`, advisory **Low** (SUP-026: **Medium**, see below); not applicable in a repository that does not track the file). One schema, shared with licence-tools (`docs/MANIFEST-SCHEMA.md`, a REUSE.toml superset with `origin-*` keys and a separate `[[snippet]]` table for line ranges), and the same checks as its reference validator `tools/licence_manifest.py`: **SUP-022 (LM-001)** the manifest does not parse or breaks the schema (an unknown key is an error); **SUP-023 (LM-002)** a required file, the notice that names `origin-copyright` on a line with `copyright`, `(c)` or the copyright sign, or the licence text is not tracked (a credit in prose is not a notice); **SUP-024 (LM-003)** a tracked file says `Origin:`, `derived from`, `ported from` or `vendored` in its first 60 lines and no entry covers it (licence texts are never read; a marker in `.md`, `.markdown`, `.rst`, `.txt` or `.tsv` is an info note; a `[[snippet]]` covers only marker lines inside its inclusive 1-based range); **SUP-025 (LM-004)** an entry's path matches nothing git tracks; **SUP-026 (LM-005)** an entry's `SPDX-License-Identifier` holds a licence its `origin-licence` forbids (a compatibility table ported from licence-tools, advisory data and not legal advice; **a conflict is Medium** because any incompatibility blocks, CireSnave 2026-11-21; an id the table lacks is an info note. Apache-2.0 into GPL-2.0-or-later conflicts; MPL-2.0 into GPL-3.0/LGPL-3.0 and LGPL-2.1-only into GPL-3.0/AGPL-3.0 are allowed; an MPL-2.0 Exhibit B notice in a covered or `requires` file limits the code to MPL-2.0). Files are enumerated from the index and read as committed at `HEAD`. Run it with `coderipper check SUP-023 --project <repo>` (any of the five ids). Not seen: copied code that carries neither a marker nor an entry. The ids are permanent (allocated 2026-11-19, `docs/DESIGN-LICENCE-ATTRIBUTION.md` section 4). Evidence: unit fixtures in the shapes of the validator's own tests, a seeded-defect and clean-twin conformance pair per rule, and a run over a clean export of Baracuda `origin/main` with a hand-written entry for `crates/baracuda-ozimmu-sys/**` (SUP-023 fires for the missing RIKEN notice).
