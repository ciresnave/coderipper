**Idea {{IDEA1}} (`RDB-002`).** Parse the Rust source files outside test code and report a function, method, binding or parameter name that is not in snake case, a type or variant name that is not in upper camel case and a constant or static name that is not in screaming snake case, unless an allow attribute names the lint. rustc's `non_snake_case`, `non_camel_case_types` and `non_upper_case_globals` lints, `typescript-eslint`'s `naming-convention` and Ruff's `pep8-naming` (named in this repository's rule documents) are published prior art.

**Idea {{IDEA2}} (`REL-002`).** Parse the Rust source files outside test code and report a loop whose own body sleeps and looks at a failure when no comparison in it names an attempt counter or limit, or when every sleep waits a fixed time written out in the call.

**Idea {{IDEA3}} (`ERR-002`).** Parse the Rust source files outside test code and report a `catch_unwind` call in a function that is not a boundary (not `main`, not in a binary target, not named for a boundary word, no comment saying why). Ruff's `BLE001` (blind except, named in this repository's rule documents) is published prior art for the idea in Python.

**Idea {{IDEA4}} (`TYP-004`).** Parse the Rust source files outside test code and report a `pub` function that takes a bare string for a parameter named for a domain value (`email`, `url`, `uuid` and the like), unless the function's own name says it is the parser or validator.

**Idea {{IDEA5}} (`ERR-007`).** Parse the Rust source files outside test code and report a hand-written release (`close`, `unlock`, `free` and the like) of a binding when a `?` or `return` statement lies between the binding and the release in the same block. Ruff's `SIM115` (named in this repository's rule documents) is published prior art for the idea in Python.

**Idea {{IDEA6}} (`OPS-007`).** Read the tracked flag registry files (`flags`, `feature-flags` and the like, as YAML, JSON or TOML) and report each flag that records no owner or no sunset date.

**Idea {{IDEA7}} (`MOD-011`, extern-block symbols).** When grading an item of a Rust crate that nothing calls, treat a `pub` function, static or type declared in an `extern` block of a module reachable through `pub` modules as exported, so that its finding is Info and not Medium.
