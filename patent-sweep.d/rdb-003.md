**Idea {{IDEA1}} (`RDB-003`).** Parse Rust source with `syn` and, per function, add one for each branching structure plus its nesting level, one per `else`, one per run of like logical operators, one per labelled jump and recursive call; report a function whose total is over a warning level and a higher error level. A visitor over the syntax tree with a nesting counter is the whole mechanism; nothing is executed.
