**Idea {{IDEA1}} (`SUP-021`).** Parse each `build.rs` with `syn` and report, once each, a path that names a socket type or an HTTP client, a file-system write in a script whose text never names `OUT_DIR`, a script text with no `rerun-if-changed` or `rerun-if-env-changed`, and an `unsafe` block, function or impl. Nothing is executed, monitored or enforced; the script is read as text.
